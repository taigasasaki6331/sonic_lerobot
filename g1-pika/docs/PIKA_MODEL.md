# PIKA付きモデル（閉状態・初期動力学試験）

## 形状の訂正（ユーザー指摘後に確認）

移植したSTL3点は、ローカルの `PikaAnyArm/piper/piper_ros/piper_description/meshes/` の
`gripper_base.STL`、`link7.STL`、`link8.STL` とSHA-256がすべて一致。
本体の質量0.145318531kgと慣性も同Piper URDFの記載と一致した。
したがって、旧リポジトリの「PIKA用」モデルという名称だけでは実物PIKAのCADとは判断できない。
今回の形状・慣性はPiperグリッパと同じ代替定義として扱う。

以下の計測結果はそのモデル内では有効だが、実物PIKA装着時の成立を示さない。
次の優先作業は実物PIKAに対応するCAD・質量・慣性の確認とモデル差し替え。
以下の「PIKA」は旧定義・フレームの名称として読むこと。

実行: `make pika-view`。画面なし: `make pika`。モデル整合と動作試験: `make check-pika`。
生成は起動時に自動で行い、元のリポジトリは書き換えない。

## 採用した定義

PIKAの形状3点・取付変換・質量・慣性・TCPは、固定PIKAリポジトリの
`src/g1_pika_description/scripts/generate_urdf.py` から取得。
移植ファイルのSHA-256と出典は `assets/pika/provenance.json`、ライセンス情報は同ディレクトリのNOTICE。
今回は元URDFと同じ左右2個の装着構成。実機の装着構成と一致するかは別途確認が必要。

| 部品 | 片側の質量 |
|---|---:|
| PIKA本体 | 0.145318531kg |
| 指A | 0.030353492kg |
| 指B | 0.030353492kg |
| PIKA計 | 0.206025515kg |

これらは旧URDFに記載された値で、今回実測した値ではない。CADの計算条件も未確認。
取付金具・配線・追加センサーの質量と慣性は未計上。実機適合の結論には使用しない。

取付位置は手首から `[0.0415, 0, 0] m`、TCP位置は手首から `[0.18, 0, 0] m`。
左右の取付姿勢は元ジェネレータをそのまま使用する。
右TCPは+X上、+Y開閉、+Z前。右トラッカーからTCPへの軸変換も保存し、行列で検証済み。
WBCの目標座標はpelvis基準。浮遊基底の移動に合わせて世界座標のTCP目標も移動する。
世界に固定した対象物の追従やLeRobotの相対actionの合成はまだ実装していない。

## 純正ハンドの置換と共通モデル

WBCのMuJoCoモデルには純正の掌の慣性が手首リンクへ合成されている。
掌の形状と指のbodyを除去し、手首は上流URDFに分離記載されている0.08457647kgの慣性へ戻したうえでPIKAを追加。
総質量は元モデル34.3942352kgから33.41319397kgとなる。PIKAを上乗せしたモデルではない。

G1部分の動力学・運動学は固定WBCのMJCFを正本に統一する。
上流URDFには次の差があり、生成するURDF側で合わせている。

- 腰rollの高さ9mm、腰pitchの高さ−19mm、肩の高さ10mmの差。
  ゼロ姿勢では差が相殺されるが、非ゼロ姿勢ではTCPに約3.7mmの差が出た。
- 頭・ロゴ・外装・支持部の慣性はMJCFでは親に集約されているため、URDF側の重複を除去。
- 他のG1リンクの重心・慣性もMJCFからURDFへ反映。

元ファイルは変更しない。`scripts/pika_model.py` が新しい
`artifacts/models/g1_pika_closed.xml` と `g1_pika_closed.urdf` を生成する。
追加PIKAの慣性は両者へ同じ定義を入れ、腕の重力補償にも使用する。

## 爪と衝突

本段階では両指を旧URDFの関節値0で固定する。29個のG1関節のみを動的に制御し、
既存WBCモデルの観測次元を維持する。開閉指令・把持・グリッパ通信は未実装。
PIKA本体と各指のSTLを衝突形状にも設定し、接触を有効にする。
MuJoCoの各meshの凸包による近似であり、凹形状や把持面の精密な接触は未検証。

## 検証結果と限界

[モデル整合試験](pika-model-check-2026-09-14.json): 30通りの関節角と基底姿勢で、
TCP位置・姿勢と関節重力トルクをPinocchioとMuJoCo間で照合。差は浮動小数点丸め程度。
自由基底、29アクチュエータ、純正ハンド除去、PIKAの衝突設定、総質量一致も確認。

[30秒動作試験](pika-30s-2026-09-14.json): 立位を維持し、右TCPを前方6cm・上方4cmへ往復。
移動量最大6.83cm、左右TCP位置誤差最大3.40cm、姿勢誤差最大0.0841rad。
IK計算の位置誤差は最大0.057mmであり、物理的な追従誤差と区別する。
MuJoCo警告0。初期の立位・動作チェックとして合格。精密な教師軌道追従の成立はまだ示していない。
OSMesaで近接画像を描画し、PIKAへの置換と赤いTCPマーカーを確認した。

次は教師軌道への接続と追従誤差の評価、その後に指定LeRobotでの推論接続。
LeRobotの責務（学習・推論）とWBCの責務（身体制御・将来の低レベル送信）は維持する。
