# ポリシー出力からTCP目標への変換

`scripts/policy_action.py` は通信・SDK・アクチュエータ依存を持たない純粋関数。
現在は追加のbridgeを介してシミュレーションWBCへ接続済み。実機は未接続。
接続・制御参照の積分・検証範囲は [POLICY_SIM.md](POLICY_SIM.md) を参照。

- actionは10D: 現在TCPに対するh1並進3、列配置rotation6D、将来グリッパ幅。
- rotation6Dはネットワークの未正規化出力としてGram-Schmidtで回転行列化。
  教師データの厳密な回転列検査とは区別する。非有限・縮退ベクトルは拒否。
- 引数の `measured_tcp_in_pelvis` はその観測時点のTCP姿勢。
  最後に送った目標姿勢を再積分するものではない。
- tracker→TCP軸変換Aは既存モデルの `[[0,0,1],[0,-1,0],[1,0,0]]`。
  `p_target = p_measured + R_measured A dp`、
  `R_target = R_measured A dR A^T`。
- グリッパ幅は値を返すだけで、開閉命令は送らない。
- 1サンプル並進2cm、回転0.2rad、幅0..0.1mを既定のシミュレーション事前検査値とした。
  超過時はクリップせず拒否。実測ハードウェア限界や安全速度の保証ではない。
- timeout、重複/欠落sequence、速度/加速度制限、通信異常時の処理、停止、
  カメラ時刻とTCP姿勢の同期、実機の座標較正は別途必要。ここでは未実装。

`make check-policy-action` で無動作・軸変換・測定姿勢へのアンカー・
予測回転の正規化・不正指令拒否・不正座標系拒否の6テストに合格。
この単体テスト自体は、モデル予測を入力した閉ループシミュレーションや実機動作の検証ではない。
