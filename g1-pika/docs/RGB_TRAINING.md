# 再現可能なRGB-only ACT学習試験

旧モデル・旧データを変更せず、深度を入力から除いた小型LeRobot ACTをCPUで新規学習する。
目的は学習・推論・保存・再読込の配線確認であり、タスク用の本学習ではない。

## 2026-09-14の結果

100ステップと500ステップで試験。学習・検証サンプルのキャッシュhashは同一で、
500ステップ試験の先頭100損失も100ステップ試験と完全一致した。
いずれも保存モデル・processorを再読込し、96フレームの生予測値の完全一致を確認。

| 検証32フレーム | 100ステップ | 500ステップ | 無動作/現在幅保持 |
| --- | ---: | ---: | ---: |
| 並進L2平均誤差 | 2.234mm | 2.514mm | 2.314mm |
| グリッパ幅MAE | 20.933mm | 3.063mm | 2.207mm |
| 負の幅出力 | 0 | 7 | 0 |

500ステップ後の検証幅は -1.621〜84.203mm。出力のクリップは行っていない。
学習側の並進誤差は1.313mmへ改善したが、検証側は100ステップ時より悪化。
今回の小標本では汎化・タスク成功を確認できず、学習処理の試験完了としてのみ扱う。

再読込後の検証推論p95は34.43ms（CPU4スレッド）。縮小済み画像のキャッシュからの計測で、
動画読込・縮小・カメラ通信・WBCは含まない。実時間30Hzの達成とは扱わない。
旧モデルと解像度・構成・評価フレームが異なるため、旧推論時間との厳密な比較でもない。
分割・除外・学習のみの統計・画像変換・コード/キャッシュhashの検査に合格。
既存教師テスト6件、Balance10秒、Python依存確認も合格。

- 500ステップ: `artifacts/rgb-smoke/run-i507ue81`（現在のlatest）

## コマンド

```bash
make train-rgb-smoke
```

既定500ステップ。短縮は `make train-rgb-smoke RGB_STEPS=100`。
実行ごとに `artifacts/rgb-smoke/run-<固有ID>/` を作り、既存runは上書きしない。
`artifacts/rgb-smoke-latest.json` だけを最新runへの参照として更新する。

保存済み最新モデルの再読込・推論:

```bash
make eval-rgb-smoke
```

保存前後の96フレームの予測値が完全一致しなければエラーにする。
データ分割・統計・除外・画像変換・ハッシュの検査は `make check-rgb-smoke`。
推論対象は記録済み画像で、カメラの実機接続やWBC送信はない。
今回の再読込試験はキャッシュ画像からの評価。動画読込・縮小も含む実時間性能の保証ではない。

## データの扱い

- 元データは `data_2608261323_valid49_g1_zero_relative_h1_final_v3`。
- 学習episode 0/1/2/3、検証episode 4/5。各16フレームをseed42で抽出し、学習64・検証32。
- episodeをまたがず、`action[t].gripper` と `state[min(t+1,last)].gripper` の差が
  1µmを超える行を対象から除外する。推測による補正・クリップ・元データ書換はしない。
- 除外数はepisode 0〜5の順に1/0/1/1/4/1。選択・除外frame indexをmanifestへ保存。
- 全parquet shardを走査。必要episodeが見つからない/16件未満なら学習を拒否する。
- これは不明なラベルを使わない小規模試験の方針であり、不一致の原因解決やデータ全体の認証ではない。
- RGB2系統をfloat32の0〜1へ変換し、bilinear/antialiasで128×96へ縮小。
  リサイズ・スケール処理は学習と推論の共通関数。深度は入力・統計・キャッシュに含めない。
  LeRobotDatasetのitem取得自体は未使用の深度を読み込む場合がある。
- 10D相対state（単位姿勢＋現在幅）と10D h1 actionは元の値を維持する。
- 正規化は学習64件だけのmean/std。検証データから統計を取らない。
  定数軸の除算安定化のためstd下限1e-6を事前固定し、統計とともに保存する。
- 同じ検証splitを100/500ステップで参照しているため、最終的な未使用テストセットの代わりにはしない。

## モデル・学習

固定LeRobot 79edf6a9のACTPolicyを直接使用。ACTのモデル実装を作り直してはいない。
chunk_size=1、n_action_steps=1、ResNet18（事前学習重みなし）、dim_model=128、heads=4、
feedforward=512、encoder=1、decoder=1、dropout=0、use_vae=false。
VAEを省いた小型設定であり、旧モデルと同じモデル構成・性能を再現する試験ではない。
AdamW lr=1e-4、weight_decay=1e-4、batch=4、grad_clip=1、seed42、CPU4スレッド、決定的演算。
LeRobotのpre/postprocessorで正規化・逆正規化し、ACTPolicy.forwardの損失で学習する。
公式train CLI全体ではなく、固定モデル/processorを使う最小ローカルループ。
新規パッケージ・事前学習重みのダウンロードなし。既存 `.venv-policy` を使用。

## 保存と限界

runには選択サンプルのsafetensors、モデル・processor、manifest、損失履歴、予測、評価を保存。
学習時スクリプトそのものを `training_script.py` に保存し、ハッシュをmanifestに記録する。
これはソースのアーカイブで、直接その場所から実行するための独立配布物ではない。
LeRobot commit、依存lockのハッシュ、元parquetのハッシュ、キャッシュのハッシュも記録する。
学習再開用のoptimizer/RNG stateは保存していない。途中再開ではなくseed固定の再学習用。
重みはローカルartifactsに保存し、Gitには入れない。削除前にrunフォルダ単位でバックアップすること。

本学習にはより多くのデータ・学習量と、独立した評価が必要。
幅の誤差、姿勢追従、動きの大きい区間での性能、推論周期、閉ループ挙動を確認するまでは
実機用ポリシーとは扱わない。GPU環境の利用・再学習ジョブの外部送信は未実施。
